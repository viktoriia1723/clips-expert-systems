# Експертні системи на базі CLIPS
Репозиторій містить результати розробки баз знань та правил у середовищі CLIPS в рамках дисципліни «Інтелектуальні інформаційні технології».

## Автор
- Студент: Кращенко Вікторія
- Група: ІН-32/2

## Структура репозиторію
- `Lab1/` – операції з фактами (assert, retract, facts);
- `Lab2/` – створення шаблонів (deftemplate) та впорядковані факти;
- `Lab3/` – формування бази правил (defrule) експертної системи;
- `Lab4/` – створення та використання функцій (deffunction);
- `Lab5/` – перетворення інфіксних виразів у префіксні та правила родинних відносин;
- `README.md` – опис проєкту.

## Висновки
Під час виконання роботи я ознайомилася з системою контролю версій Git та сервісом GitHub, створила репозиторій, сформувала структуру папок для лабораторних робіт і завантажила файли CLIPS. Я навчилася створювати файли та папки через вебінтерфейс, робити коміти з описом змін і оформлювати README.md у форматі Markdown. Труднощі виникли зі створенням папок: одна з них випадково опинилася всередині іншої, але я виправила це, змінивши шлях до файлу під час редагування.
